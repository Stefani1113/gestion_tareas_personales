## Versión de Laravel usada:
Laravel Framework 12.58.0

## Pasos para correr el proyecto:

## 1
Clonar el repositorio de git en la carpeta que decees, git clone https://github.com/Stefani1113/gestion_tareas_personales

## 2
Instalar dependencias, composer install y luego npm install

## 3
Generar una copia del archivo de configuración .env,  cp .env.example .env

## 4 
Entra a VS y cambia los datos de la base de datos del archivo .env por los datos de tu motor de base de datos local 

## 5
Generar llave de la aplicación, php artisan key:generate

## 6
Preparar base de datos local y compilar el diseño, php artisan migrate, y luego 
npm run build

## 7
Por último se enciendes el servido local, php artisan serve
